# project-route-autonomous-vehicles
Data science project exploring autonomous vehicle performance and predicting journey problems.
# Can We Trust the Ride? - Autonomous Vehicle Data Analysis

## Project Overview
This project explores factors associated with autonomous vehicle journey problems using data science and machine learning.

The analysis investigates weather conditions, road environments, sensor performance and human interventions to identify patterns and predict potential journey problems.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning
Two classification models were developed and evaluated:
- Logistic Regression
- Decision Tree

Logistic Regression achieved 94.4% accuracy and 98.0% recall on the test dataset.

## Dataset
The project uses synthetic autonomous vehicle journey data for educational purposes. The results should not be interpreted as evidence of real-world vehicle safety.

## Project Structure
- `autonomous_vehicle_analysis.ipynb` – Data preparation, exploratory analysis, visualisations and machine learning models.
- `README.md` – Project description and overview.
